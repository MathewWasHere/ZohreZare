======================================================================
 راهنمای نصب سایت زهره زارع روی هاست cPanel
======================================================================

این بسته یک سایت کاملاً «استاتیک» است: هیچ دیتابیس، PHP، Node یا
تنظیم سروری لازم ندارد. فقط فایل‌ها را در public_html بگذارید.


----------------------------------------------------------------------
گام ۱ — ورود و رفتن به File Manager
----------------------------------------------------------------------
۱. وارد cPanel هاست شوید.
۲. بخش Files ← روی «File Manager» کلیک کنید.
۳. وارد پوشه‌ی public_html شوید.
   (اگر سایت را روی یک دامنه‌ی فرعی نصب می‌کنید، وارد پوشه‌ی همان
    دامنه شوید، نه public_html.)


----------------------------------------------------------------------
گام ۲ — خالی کردن پوشه (فقط اگر سایت قبلی دارید)
----------------------------------------------------------------------
اگر از قبل چیزی در public_html هست (مثلاً صفحه‌ی پیش‌فرض هاست یا
نسخه‌ی قدیمی سایت)، اول از آن یک بکاپ بگیرید و بعد فایل‌های قدیمی
را پاک کنید تا با فایل‌های جدید قاطی نشوند.

نکته: فایل‌های cgi-bin و .well-known را دست نزنید.


----------------------------------------------------------------------
گام ۳ — آپلود و استخراج
----------------------------------------------------------------------
۱. دکمه‌ی «Upload» بالای File Manager را بزنید.
۲. فایل zohrezare-cpanel.zip را آپلود کنید (چند ده مگابایت است،
   کمی طول می‌کشد).
۳. به public_html برگردید و صفحه را Refresh کنید.
۴. روی فایل zip راست‌کلیک کنید ← «Extract» ← تأیید.
۵. فایل‌ها مستقیم داخل همان پوشه باز می‌شوند (index.html باید
   دقیقاً در public_html باشد، نه داخل یک زیرپوشه).
۶. بعد از باز شدن، خود فایل zip را پاک کنید.


----------------------------------------------------------------------
گام ۴ — نمایش فایل‌های مخفی و بررسی .htaccess
----------------------------------------------------------------------
فایل .htaccess با نقطه شروع می‌شود و ممکن است دیده نشود:
   Settings (بالا سمت راست) ← گزینه‌ی «Show Hidden Files (dotfiles)»
   را تیک بزنید ← Save.

مطمئن شوید .htaccess کنار index.html وجود دارد. این فایل مسئول
فشرده‌سازی، کش مرورگر، هدرهای امنیتی و صفحه‌ی ۴۰۴ است.


----------------------------------------------------------------------
گام ۵ — فعال کردن SSL و انتقال به HTTPS  (مهم)
----------------------------------------------------------------------
۱. در cPanel ← بخش Security ← «SSL/TLS Status».
۲. دامنه را انتخاب و «Run AutoSSL» را بزنید و صبر کنید تا گواهی صادر شود.
۳. مطمئن شوید https://zohrezare.ir بدون خطا باز می‌شود.
۴. حالا فایل .htaccess را ویرایش کنید (راست‌کلیک ← Edit) و در بخش
   شماره ۱، علامت # را از ابتدای این شش خط بردارید:

       RewriteCond %{HTTPS} !=on
       RewriteCond %{HTTP:X-Forwarded-Proto} !https
       RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
       RewriteCond %{HTTP_HOST} ^www\.(.+)$ [NC]
       RewriteRule ^ https://%1%{REQUEST_URI} [L,R=301]

۵. ذخیره کنید. از این به بعد همه‌ی بازدیدها به نسخه‌ی امن منتقل می‌شوند.

⚠️ این کار را قبل از فعال شدن SSL انجام ندهید، سایت از دسترس خارج می‌شود.
⚠️ سایت به‌عنوان PWA (قابل نصب روی موبایل) فقط روی HTTPS کار می‌کند.


----------------------------------------------------------------------
گام ۶ — تست نهایی
----------------------------------------------------------------------
این آدرس‌ها را یک‌بار باز کنید:

   /                      صفحه‌ی اصلی
   /services.html         فهرست خدمات
   /booking.html          رزرو وقت
   /panel/index.html      پنل کاربری
   /یک-آدرس-الکی          باید صفحه‌ی ۴۰۴ خودمان بیاید

اگر تصاویر یا فونت‌ها نیامدند، یک‌بار با Ctrl+F5 صفحه را تازه کنید.


----------------------------------------------------------------------
تنظیمات سایت (بدون نیاز به برنامه‌نویس)
----------------------------------------------------------------------
شماره تماس، آدرس، لینک اینستاگرام و واتساپ، متن‌ها و کد ادمین همگی
در این فایل هستند:

   assets/js/core/config.js

می‌توانید در File Manager همان فایل را Edit کنید و ذخیره کنید.
بعد از هر تغییر، یک‌بار با Ctrl+F5 صفحه را باز کنید.

نکته درباره‌ی پنل: نسخه‌ی فعلی حالت نمایشی است؛ اطلاعات نوبت‌ها در
مرورگر خود کاربر (localStorage) ذخیره می‌شود و کد تأیید ثابت ۱۲۳۴ است.
برای نوبت‌دهی واقعی و چند‌کاربره، به یک بک‌اند نیاز است که آدرسش در
همان config.js بخش api.baseUrl تنظیم می‌شود.


----------------------------------------------------------------------
به‌روزرسانی سایت در آینده
----------------------------------------------------------------------
نسخه‌ی جدید zip را آپلود و Extract کنید و روی فایل‌های قبلی بنویسید.
چون سایت PWA است و سرویس‌ورکر دارد، بعد از آپدیت یک‌بار Ctrl+F5 بزنید
تا نسخه‌ی تازه بارگذاری شود. (تنظیمات کش در .htaccess طوری است که
فایل service-worker.js هیچ‌وقت کش نمی‌شود و آپدیت‌ها می‌رسند.)


----------------------------------------------------------------------
این فایل را بعد از نصب می‌توانید پاک کنید.
دسترسی عمومی به آن در .htaccess بسته شده است.

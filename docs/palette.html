نقش‌های معنایی

در کد سایت به‌جای رنگ خام، از این نقش‌ها استفاده می‌شود. برای تغییر تم کافی است همین‌ها عوض شوند.

نقشاشاره بهمقدارکاربرد
--bg var(--cream-50) #FFFCFA پس‌زمینه‌ی اصلی صفحه
--bg-soft var(--cream-100) #FAF4EF پس‌زمینه‌ی بخش‌های یک‌درمیان
--bg-elevated #FFFFFF #FFFFFF کارت‌ها و سطوح بالاتر
--text var(--ink-900) #15100E متن اصلی
--text-soft var(--ink-700) #45332B متن ملایم
--text-muted var(--ink-500) #6B564C متن کم‌اهمیت و توضیحات
--line rgba(21, 16, 14, 0.14) #15100E خطوط و حاشیه‌ها
--line-strong rgba(21, 16, 14, 0.26) #15100E حاشیه‌های پررنگ‌تر
--accent var(--rose-500) #A55C44 رنگ تاکید (دکمه‌ها و لینک‌ها)
--accent-soft var(--blush-100) #FBE6DF زمینه‌ی ملایم تاکید
